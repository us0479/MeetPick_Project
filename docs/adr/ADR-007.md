# ADR-007: Frontend를 React + TypeScript + Vite로 구성한 이유

- Status: Accepted
- Context: 프론트 전담 인원 없이 A/B/C가 자신의 API를 실제 화면에서 검증해야 하며 SSR은 요구사항이 아니다.
- Decision: React + TypeScript + Vite SPA를 사용하고 Spring Boot API를 소비한다. Node.js는 프론트 개발/빌드 도구로만 사용한다.
- Alternatives: Next.js, 서버 템플릿, Swagger만으로 시연.
- Consequences: 프론트 구조가 단순하고 API 경계가 명확하다. 고급 UI/SSR/프론트 테스트는 범위에서 제외한다.
- Verification: Vite build 성공, React → `/actuator/health` smoke test, 배포 URL SPA refresh 확인.
