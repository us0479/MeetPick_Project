# ADR-004: durationMinutes 기반 연속 Window 추천을 선택한 이유

- Status: Accepted
- Context: 단일 30분 slot의 참석 가능 인원만 높아도 실제 90/120분 약속을 잡을 수 없는 문제가 있다.
- Decision: 후보는 `durationMinutes`를 만족하는 연속 30분 window로 생성한다. 정렬은 참석 가능 인원 DESC → 선호도 합계 DESC → 시작시간 ASC, 이후 유사 후보를 제거하고 TOP3를 저장한다.
- Alternatives: 단일 slot 추천, 최장 공통구간만 반환.
- Consequences: 계산 로직이 증가하지만 실제 약속 소요시간을 보장한다.
- Verification: 30/60/90/120분 케이스, 경계/동점/유사 후보 제거 테스트.
