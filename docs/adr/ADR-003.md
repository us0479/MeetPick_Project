# ADR-003: Availability를 Slot이 아닌 시간 구간으로 저장하는 이유

- Status: Accepted
- Context: 사용자가 18:00~21:00을 입력할 때 30분 단위 row를 여러 개 영속화하면 저장량·수정 복잡도와 slot granularity 의존성이 커진다.
- Decision: DB에는 사용자가 입력한 원본 `[startAt, endAt)` 구간과 priority를 저장하고 추천 계산 시 메모리에서 30분 slot으로 변환한다.
- Alternatives: 30분 TimeSlot row 영속화, JSON 배열 저장.
- Consequences: overlap/range 검증이 필요하지만 원본 의도를 보존하고 향후 slot 간격 변경에 유연하다.
- Verification: 범위·overlap 검증 테스트, 같은 입력의 slot 변환 결과 테스트.
